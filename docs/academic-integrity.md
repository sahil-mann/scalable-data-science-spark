# Academic Integrity and Public Release

This repository is a portfolio reinterpretation of completed coursework. It should not publish material that could function as an answer key for current students.

## Material excluded from the public repository

- Assignment question sheets and grading rubrics
- Course-provided starter notebooks
- Full submitted reports and milestone updates
- Private feedback and marking documents
- Institution-managed storage credentials or paths
- Raw source data, checkpoints, generated outputs, or model files
- Code cells whose only purpose is to reproduce a course-specific answer verbatim

## Material suitable for publication

- Independently written case-study summaries
- Selected figures created from the completed analysis
- Reusable Spark engineering patterns after credential review
- General-purpose validation and evaluation utilities
- Architecture diagrams, lessons learned, limitations, and future work

Before publication, confirm that the course has finished and that the institution permits public portfolio presentation of independently produced work.
