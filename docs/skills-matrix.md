# Skills Matrix

| Capability | Climate case study | Music case study |
|---|---|---|
| Distributed data inspection | HDFS metadata and annual-file inventory | Storage inventory across metadata, features, genres, and interactions |
| Schema engineering | Fixed-width metadata and typed daily records | Programmatic schemas from attribute definitions |
| Data validation | Bidirectional station-ID checks | Missing IDs, repeated rows, one-to-one mappings, cold-start checks |
| Join design | Key-only anti joins and metadata enrichment | Sequential feature joins and genre intersection audits |
| Feature engineering | Station-year and country-year summaries | Variance screening, correlation filtering, scaling, class weights |
| Machine learning | Descriptive climate analysis | Binary classification, multiclass classification, implicit ALS |
| Evaluation | Coverage, data support, anomalies | AUROC, AUPR, F1, confusion matrices, Precision@10, NDCG@10, MAP@10 |
| Performance engineering | Reduced grain before expensive joins | Checkpointing, bounded samples, memory-aware model fitting |
| Visual communication | Maps, temperature series, rainfall choropleth | Heatmaps, class imbalance, model trade-offs, recommendation metrics |
| Critical interpretation | Changing station coverage and sparse country-years | Imbalanced classes, cold start, offline-metric limitations |
